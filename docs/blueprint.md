# **App Name**: VersaFolio

## Core Features:

- Hero Section: Display name, role, and a brief description with 'View Projects' and 'Download CV' buttons, plus a profile image, animated with Framer Motion.
- About Section: Present a personal summary, mission statement, and key info in a two-column layout, enhanced with a developer photo.
- Skills Grid: Showcase skills categorized into Frontend, Backend, Mobile, and Tools, using skill cards with relevant icons.
- Projects Showcase: Display project cards with thumbnails, titles, descriptions, tech stack tags, and 'Live Demo' and 'GitHub' buttons, featuring hover animations.
- Experience Timeline: Create a vertical timeline to detail work experiences with titles, company names, durations, and key responsibilities, laid out in a modern design.
- Contact Form: Implement a contact form (no backend submission) with fields for email and social media links, plus supporting icons.
- Dark Mode Toggle: Enable users to switch between light and dark themes via a toggle in the navbar, using React Context to manage state.

## Style Guidelines:

- Primary color: Deep green (#38A169) for a modern, tech-focused aesthetic.
- Background color: Very light desaturated indigo (#F9FAFB) for a clean, unobtrusive backdrop in light mode; dark gray-blue (#0F172A) in dark mode.
- Accent color: Slightly light green (#48BB78) to add depth and subtly draw attention to key elements.
- Font: 'Inter', a versatile sans-serif suitable for both headlines and body text.
- Use a consistent set of icons for skills, contact info, and other UI elements. All icons should be simple, modern, and filled.
- Implement a responsive design using a 12-column grid on desktop, 6-column grid on tablet, and 4-column grid on mobile.
- Incorporate smooth scrolling, fade-in effects, and hover animations to enhance user experience and provide visual feedback.
